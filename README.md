# 👶 בייבי יומן - אפליקציית מעקב תינוקות והתפתחות (PWA)

אפליקציית ווב מותאמת למובייל (PWA) המיועדת להורים טריים למעקב קל, מהיר ומסונכרן בזמן אמת.

---

## ✨ פיצ'רים עיקריים

1. **מעקב האכלות (הנקה ובקבוק):**
   * **סטופר הנקה חי:** מדידת זמנים נפרדת לשד ימין ושד שמאל + כפתור פאוזה וחישוב אוטומטי של סה"כ זמן.
   * **בקבוק:** כפתורי כמות מהירים (30, 60, 90, 120, 150 מ"ל) ובחירת סוג החלב (שאוב או תמ"ל).
   * **הזנה ידנית:** הוספת שעת תחילת וסיום האכלה בדיעבד.

2. **החלפת טיטולים:**
   * כפתורי לחיצה מהירה אחת (1-Tap): 💧 **פיפי** | 💩 **קקי** | 💧💩 **שניהם**.
   * תיעוד צבע יציאה (צהוב חרדלי, ירוק וכו') ומרקם עבור טיפת חלב/רופא.

3. **מעקב שינה:**
   * טיימר שינה חי ("נרדמה כעת" ➔ "התעוררה!").
   * הזנת שעות שינה ידנית.

4. **מעקב משקל וגדילה:**
   * תיעוד שקילות, השוואה לשקילה קודמת ולמשקל הלידה.

5. **מדריך התפתחות ומשימות מותאמות גיל (טיפת חלב):**
   * **חישוב גיל אוטומטי:** שבועות, ימים וחודשים מתאריך הלידה.
   * **מה מצופה בגיל הזה:** אבני דרך מפורטות (ראייה, תנועה, חיוך חברתי, הרמת ראש). כולל אפשרות סימון V עם חגיגת קונפטי! 🎉
   * **משימות ותרגילים מומלצים:** זמן בטן, כרטיסיות שחור-לבן, מגע עור לעור (קנגורו), עיסוי לגזים וכו'.

6. **סנכרון מלא בין מכשירים בזמן אמת (Supabase):**
   * שני ההורים מחוברים לאותה התינוקת דרך "קוד משפחה" או קישור ישיר בוואטסאפ.
   * עדכון של הורה אחד קופץ מיד בטלפון של ההורה השני!

7. **ייצוא ל-Excel / Google Sheets:**
   * הורדת כל היסטוריית הפעולות לקובץ CSV תואם עברית שניתן להעלות ישירות ל-Google Sheets.

8. **התקנה בגלקסי בלי חנות (PWA):**
   * עובד כמו אפליקציה רגילה במסך מלא, ללא שורת כתובת, עם אייקון מעוצב במסך הבית.

## 🚀 הרצה מקומית

```bash
npm install
npm run dev
```

---

## 🌐 העלאה ל-Render (סטטיק ווב חינמי)

1. צור חשבון ב-[Render.com](https://render.com).
2. צור **New Static Site**.
3. חבר את ה-Git Repository שלך.
4. הגדרות Build:
   * **Build Command:** `npm run build`
   * **Publish Directory:** `dist`
5. לחץ **Create Static Site** – ותקבל קישור חינמי תוך דקה!

---

## 🗄️ חיבור Supabase (בסיס נתונים חינמי לסנכרון)

1. צור פרויקט חינמי ב-[Supabase.com](https://supabase.com).
2. גש ל-**SQL Editor** ב-Supabase.
3. פתח את הקובץ `supabase-schema.sql` שנמצא כאן בפרויקט, הדבק את התוכן והפעל אותו (**Run**).
4. העתק את ה-**Project URL** ואת ה-**Anon Public Key** (נמצאים ב-Project Settings -> API).
5. באפליקציה: לחץ על סמל הענן/הגדרות והדבק אותם – זהו! הכל מסונכרן בזמן אמת.
